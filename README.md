# AkaSystems · web

Web principal de AkaSystems (akasystems.es). Página estática en un solo archivo, `index.html`, con el CSS de Tailwind ya compilado dentro.

## Publicación

Vercel publica automáticamente cada cambio que se sube a la rama `main`. No hace falta comando de build.
